# 🛡️ نظام مراقبة دخول الأجهزة للشبكة
# Network Device Monitoring System

## 📋 المتطلبات / Requirements
- Python 3.10+
- pip

## 🚀 تشغيل النظام / How to Run

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق
```bash
# Windows (تشغيل عادي):
python app.py

# Linux/macOS (يحتاج صلاحيات للفحص الكامل بـ Scapy):
sudo python app.py
```

### 3. فتح الواجهة
اذهب إلى: **http://localhost:5000**

---

## 📁 هيكل الملفات / File Structure

```
network_monitor/
├── app.py           ← التطبيق الرئيسي (Flask)
├── scanner.py       ← وحدة فحص الشبكة (Scapy / ARP)
├── whitelist.py     ← إدارة الأجهزة الموثوقة
├── alerts.py        ← التنبيهات والسجلات
├── whitelist.json   ← قاعدة بيانات الأجهزة الموثوقة
├── alerts.json      ← سجل التنبيهات (ينشأ تلقائياً)
├── requirements.txt ← المكتبات المطلوبة
└── templates/
    └── index.html   ← واجهة المستخدم
```

---

## ⚙️ المميزات / Features

| الميزة | الوصف |
|--------|-------|
| 🔍 فحص الشبكة | يفحص جميع الأجهزة في نطاق IP محدد باستخدام ARP |
| ✅ القائمة الموثوقة | إضافة وحذف الأجهزة المصرح بها |
| ⚠️ التنبيهات | تنبيه فوري عند اكتشاف جهاز غير معروف |
| 📊 لوحة تحكم | واجهة ويب عربية احترافية |
| 💾 السجلات | حفظ التنبيهات في ملف JSON |

---

## 🔧 ملاحظات / Notes

- **Scapy** تحتاج صلاحيات root/admin للفحص الكامل
- بدون صلاحيات: يعمل النظام بجدول ARP المحلي (أجهزة سبق التواصل معها)
- **Wireshark** يمكن استخدامه بجانب النظام لتحليل الحزم بشكل أعمق
